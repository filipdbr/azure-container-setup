# Ansible Provisioning

This directory contains the Ansible configuration responsible for server setup, including Docker installation and container deployment.

## Missing inventory.ini?

The `inventory.ini` file is intentionally excluded from this repository. It is dynamically generated by Terraform during the `terraform apply` step. 

Terraform uses the `local_file` resource to retrieve the newly created Azure VM's public IP and generates the inventory file in this directory. 

Note: The `inventory.ini` file is added to `.gitignore` and should never be committed to the repository.
